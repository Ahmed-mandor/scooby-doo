# 🎡 Scooby Doo - ملاهي سكوبي دوو (نادي الشرطة)

نظام إدارة متكامل وشامل لملاهي ومراكز ألعاب الأطفال - فرع نادي الشرطة.

---

## 🌟 مميزات النظام (Key Features)

- **إدارة التذاكر والألعاب:** حجز وإصدار التذاكر السريعة مع حساب التوقيت والرسوم الإضافية.
- **إدارة المبيعات والبوفيه:** نقاط بيع سريعة (POS) للمأكولات والمشروبات والمشتريات.
- **إدارة الورديات والخزائن:** فتح وإغلاق الشيفتات، تتبع الإيرادات، المصروفات، وتأكيد العهدة المالية.
- **تكامل سحابي فوري (Supabase Cloud Sync):**
  - مزامنة فورية للبيانات بين جميع الأجهزة.
  - دعم العمل بدون إنترنت (Offline Mode) مع المزامنة التلقائية عند استعادة الاتصال.
  - حماية تامة ضد تضارب البيانات وفقدان العمليات.
- **تقارير مالية وإحصائية:** لوحة تحكم تفاعلية لعرض أرقام المبيعات، الحجوزات، والأرباح اللحظية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** HTML5, Modern CSS3 (Custom Design System, Glassmorphism, Responsive UI), Vanilla JavaScript (ES6+).
- **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL Database, Realtime Subscriptions, REST API).
- **Security & Storage:** LocalStorage Cache Fallback with Schema Validation.

---

## 🚀 طريقة التشغيل (Getting Started)

1. قم بفتح ملف `index.html` في أي متصفح حديث (Chrome / Edge / Firefox).
2. النظام سيتصل تلقائياً بقاعدة بيانات Supabase المدمجة مع ظهور مؤشر الاتصال السحابي الأخضر أعلى الصفحة.
